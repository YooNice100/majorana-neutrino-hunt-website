Methods

Machine learning pipelines for pulse shape discrimination classification and continuous energy regression from germanium detector waveforms.

Pipeline

Overall Pipeline

End-to-end flow from raw waveforms to model predictions.

01

Waveform Ingestion

Load raw waveforms from HDF5 files. Apply baseline correction and pole-zero cancellation to normalize detector response.

↓

Feature Extraction

Compute 26 physics-informed features spanning time-domain, tail, gradient, and frequency-domain characteristics.

↓

Model Training

Train classification models (SSE vs MSE) and regression models (energy estimation) on extracted feature vectors.

↓

Evaluation

Classification

Classification Models

Distinguishing signal-like single-site events (SSE) from background multi-site events (MSE).

Random Forest

Ensemble of decision trees trained on engineered features. Robust to outliers and provides feature importance rankings.

Gradient Boosting

Sequential boosting approach that iteratively corrects misclassified events for high precision on imbalanced data.

Neural Network

Fully connected network trained end-to-end on feature vectors, capturing non-linear decision boundaries.

Regression

Regression Models

Estimating continuous energy values from waveform features. Currently in progress.

⚗️ Regression results are in progress and will be updated as experiments are finalized.
Ridge Regression

Regularized linear model providing a baseline for energy estimation from feature vectors.

XGBoost Regressor

Gradient boosted trees adapted for continuous target prediction with strong generalization.

Evaluation

Evaluation Strategy

Metrics and validation methodology used to assess model performance.

AUC-ROC

Area under the ROC curve used as the primary classification metric, robust to class imbalance.

Precision & Recall

Evaluated at signal-retaining thresholds to quantify the trade-off between background rejection and signal efficiency.

RMSE

Root mean squared error used to measure energy regression accuracy against ground-truth labels.

Cross-Validation

Stratified k-fold splits ensure both classes are represented across all training and validation folds.
