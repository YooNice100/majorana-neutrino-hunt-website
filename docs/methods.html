Methods

Classification

We trained multiple models to classify waveform events as signal-like single-site events (SSE) or background-like multi-site events (MSE).

  • Baseline: Logistic Regression
  • Tree-based: Random Forest
  • Model comparison using F1 score
  • Threshold tuning to balance precision and recall
  • Confusion matrix analysis

Due to class imbalance, F1 score was used as the primary evaluation metric rather than accuracy.

Regression

We developed regression models to predict continuous energy values from engineered waveform features.

  • Baseline: Linear and Ridge Regression
  • Improved: Random Forest Regressor
  • Evaluation using MSE and RMSE
  • 5-fold cross-validation

Model performance was evaluated by comparing training and validation error to monitor overfitting.

All preprocessing steps, including feature scaling and missing value imputation, were implemented within scikit-learn pipelines to ensure consistent and reproducible model training.
