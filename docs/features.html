Feature Engineering

Time-Domain Features

We extract features directly from waveform shape to capture pulse timing and structure.

  • LQ80 and ND80
  • Half-Width Peak (HWP)
  • Peak-to-Peak Ratio (PPR)
  • Energy Duration (ED)
  • Drift time metrics (tdrift10, tdrift50)

Frequency-Domain Features

Frequency-based features help distinguish signal-like and background-like pulse shapes.

  • Spectral Centroid Power
  • Total Power
  • Current Skewness and Kurtosis
  • Tail slope characteristics

All features are engineered with detector physics in mind, capturing charge drift behavior and pulse shape differences between single-site and multi-site events. These engineered features form the input space for both classification and regression models.
