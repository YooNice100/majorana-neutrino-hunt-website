Source

Data Source

Raw waveform data from the Majorana Demonstrator germanium detector array.

Our dataset consists of detector waveforms collected by the Majorana Demonstrator experiment. Each waveform represents charge collection behavior in high-purity germanium (HPGe) detectors, which are among the most sensitive instruments for searching for neutrinoless double beta decay.

The Majorana Demonstrator was operated at the Sanford Underground Research Facility (SURF) in Lead, South Dakota, shielded from cosmic rays to reduce background noise.

Structure

Data Structure

Format and organization of the raw waveform files.

HDF5 Files

Waveforms stored in HDF5 format for efficient hierarchical data access and compression.

Time Series

Fixed-length time-series samples capturing the full charge pulse from each detector event.

Event Level

Each entry corresponds to a single physics event, with waveform and metadata stored together.

Labels

Event Labels

Ground-truth annotations used for supervised learning tasks.

PSD Labels

Event-level pulse shape discrimination labels classifying events as single-site (SSE) or multi-site (MSE).

Energy Labels

Continuous energy values in keV used as targets for regression model training and evaluation.
