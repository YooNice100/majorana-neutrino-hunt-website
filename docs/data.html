Data

Our dataset consists of detector waveforms collected by the Majorana Demonstrator experiment. Each waveform represents charge collection behavior in high-purity germanium detectors.

  • Waveforms stored in HDF5 files
  • Fixed-length time-series samples
  • Event-level labels for PSD classification
  • Energy labels for regression analysis

Key challenges in the dataset:

  • Class imbalance across PSD labels
  • Noise and baseline drift between detectors
  • Feature stability across files
  • Large file sizes requiring preprocessing
