Results

Classification Results

We evaluated multiple classification models for predicting single-site versus multi-site events. Due to class imbalance, F1 score was used as the primary evaluation metric.

  • Final Model: Random Forest (psd_label_lq)
  • Primary Metric: F1 Score
  • Precision and Recall analyzed for false positive / false negative balance

Random Forest performed similarly to XGBoost but was selected due to stability and comparable performance with simpler tuning.

Regression Results

Regression models were trained to predict continuous energy values from engineered waveform features.

  • Baseline: Linear / Ridge Regression
  • Improved Model: Random Forest Regressor
  • Evaluation Metrics: MSE and RMSE
  • 5-fold Cross Validation

The Random Forest Regressor reduced validation error compared to the baseline linear model, though some overfitting was observed based on the training-validation gap.
