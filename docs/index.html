Introduction

The goal of our research is to support the search for neutrinoless double beta decay by applying machine learning to detector waveform data from the Majorana Demonstrator experiment. This rare process is expected to occur in single-site events (SSE), while background interactions often produce multi-site events (MSE).

To improve event identification, we engineered physics-informed waveform features that capture pulse shape, timing, and frequency characteristics. These features were used to train classification models that distinguish signal-like SSE from background-like MSE, and regression models to estimate continuous energy values.
